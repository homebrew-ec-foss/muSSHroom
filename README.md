# muSSHroom : SSH-Chat inspired terminal messaging application written in Go

## 🍄 Welcome To MuSSHroom!

This project was created as a part of a Homebrew event TILDE 5.0, by Ananya Abhilash and Thanmay Shetty.

🧋 MuSSHroom is an SSH chat server with features like slash commands, personal chatroom creation etc. To join the chat, simply enter the following command in your terminal after running the server :
```ssh localhost -p 3000 //as of now```
